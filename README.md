# 가사영상 제작기

음악 하나 + 사진 몇 장 + 가사를 넣으면 **자막이 흐르는 영상**이 됩니다.
설치도 가입도 없습니다. 주소만 열면 바로 쓰입니다.

👉 **https://60aimake.github.io/simple-lyric-scene-maker/**

`v2.9.3` · 2026-11-21

> 가사영상을 아직도 몇 시간씩 만드시나요?
> 영상 편집 프로그램을 쓰지 않습니다. 걸리는 시간은 몇 분입니다.

---

## 쓰는 법 — 여섯 단계

```
1. 가사 넣기      한 줄에 한 소절씩 적습니다.  영문 가사도 따로 넣을 수 있습니다
2. 음원 넣기      MP3 · M4A · WAV · AAC · FLAC · 동영상(소리만) 전부 됩니다
3. 배경 사진      최대 20장
4. 타이밍 맞추기  ★ 숫자를 적지 않습니다
                  재생을 누르고, 그 가사가 나올 때 그 줄을 누르면 시간이 찍힙니다
                  틀리면 화살표로 0.1초씩 밉니다
5. 글씨·화면      크기 · 색 · 글꼴 · 가로(1280×720) / 세로(720×1280)
6. 영상 만들기    처음 10초만 미리 볼 수도 있습니다
```

---

## 가사를 다시 쓰지 않는 길

```
★ 가사 파일(.txt · .lrc)을 화면에 **끌어다 놓으면** 됩니다
   가사 · 영문 가사 · 타이밍이 한꺼번에 들어갑니다
   이 도구가 저장한 백업 파일도 그대로 되읽습니다
```

```
⚠️ 만드는 중에는 **새로고침(F5)을 누르지 마십시오**
   넣어 둔 사진·음악·가사가 모두 사라집니다
   가사를 바꾸려면 새로고침 대신 글 파일을 끌어다 놓으십시오
```

---

## 안전

**사진과 음원이 기기 밖으로 나가지 않습니다.** 서버로 아무것도 보내지 않습니다.
모든 처리는 이 페이지 안에서만 일어납니다.

## 알아 두실 것

```
화면      가로 1280 × 720  ·  세로 720 × 1280
속도      PC 15 fps · 모바일 6 fps  (기기가 실제로 낼 수 있는 값에 맞췄습니다)
자막      넘치면 줄을 나누고, 그래도 넘치면 글씨를 줄입니다.  잘리지 않습니다
글꼴      무료 폰트 파일을 올려 자막·제목·닉네임에 한 번에 적용할 수 있습니다
```
